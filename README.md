# Calculator Project

## 1. Project Description
The Calculator Project is a simple Java application designed to perform basic arithmetic operations. It helps users perform mathematical calculations quickly and accurately.

## 2. Objectives
- Perform basic mathematical calculations.
- Understand Java programming concepts.
- Practice using variables, operators, conditional statements, and switch cases.
- Handle invalid operations such as division by zero.

## 3. Features
- Addition
- Subtraction
- Multiplication
- Division
- User input through the console
- Division-by-zero handling

## 4. Technologies Used
- Programming Language: Java
- IDE: VS Code, Eclipse, or IntelliJ IDEA
- JDK: Java Development Kit

## 5. Project Structure
```text
Calculator-Project/

```

## 6. How to Run the Project

### Step 1: Install Java
Install the Java Development Kit (JDK) on your computer.

### Step 2: Compile the Program
Open a terminal in the project directory and run:

```bash
javac Calculator.java
```

### Step 3: Execute the Program
Run the following command:

```bash
java Calculator
```
